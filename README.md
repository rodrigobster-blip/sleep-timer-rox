# Sleep Timer Rox V1 (Android Nativo)

Aplicación Android nativa (Kotlin + Jetpack Compose) sin publicidad y 100% sin conexión a internet (no solicita permiso `INTERNET`).

## Cómo obtener la APK instalable SIN instalar Android Studio

1. Crea una cuenta gratuita en [github.com](https://github.com) (si no tienes una).
2. Crea un nuevo repositorio (puede ser privado o público) en `github.com/new`.
3. Sube todo el contenido de esta carpeta (asegúrate de incluir la carpeta oculta `.github/workflows/build-apk.yml`).
4. Abre la pestaña **Actions** en tu repositorio de GitHub.
5. Verás ejecutarse automáticamente **Build Sleep Timer Rox V1 APK** (~2 minutos).
6. Al terminar en verde, haz clic en la ejecución y descarga el archivo **Sleep-Timer-Rox-V1-APK** en la sección *Artifacts*.
7. Descomprime ese ZIP y pasa `Sleep-Timer-Rox-V1.apk` a tu teléfono Android para instalarlo.

## Consejo para que funcione toda la noche con la pantalla apagada

En teléfonos Xiaomi (MIUI/HyperOS), Samsung o Huawei, abre la app y pulsa **Permitir ejecución con pantalla apagada** (o en Ajustes > Batería > Sin restricciones para *Sleep Timer Rox V1*).
